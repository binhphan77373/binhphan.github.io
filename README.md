## Triển khai

Trang web sử dụng GitHub Pages để hosting. Để tự triển khai:

1. Fork repository này
2. Vào **Settings → Pages**
3. Chọn branch `main` và folder `/ (root)`
4. Trang web sẽ tự động được publish tại `https://<username>.github.io/<repo-name>/`
